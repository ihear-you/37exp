# [37exp]

Архив плёночных кадров: лента для случайных встреч, папки для целенаправленного просмотра.
Бриф: [brief-mvp.md](brief-mvp.md).

**Это кликабельный прототип.** Кадры настоящие, но «уже загруженные»: они лежат прямо в проекте.
Ничего не сохраняется, базы и входа нет: кнопка «Загрузить» в шапке открыта всем. Цель прототипа: проверить сетку ленты и фон.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

## Что где

| Экран | Адрес | Файл |
| --- | --- | --- |
| Лента | `/` | `app/components/Feed.tsx`, `Masonry.tsx` |
| Папки | `/rolls` | `app/components/RollsBrowser.tsx` |
| Плёнка | `/rolls/[id]` | `app/rolls/[id]/page.tsx` |
| Кадр на весь экран | поверх ленты и плёнки | `app/components/Lightbox.tsx` |
| Загрузка | `/upload` | `app/components/UploadPrototype.tsx` |

Логика без интерфейса лежит в `lib/`:

- `catalog.ts`: справочники плёнок и камер, плёнки прототипа, сборка названия («Kodak Gold 200 · июль 2025»).
- `feed.ts`: режимы ленты (вперемешку, по цвету, тёплые, холодные, светлые, тёмные, ч/б) и правила ритма.
- `masonry.ts`: раскладка сетки без обрезки кадров.
- `folder-name.ts`: подсказка по названию папки при загрузке.

## Ленту можно настраивать

Правила, которые бриф оставил на прототип, собраны в одном месте:

- **Пороги режимов цвета и яркости:** `lib/feed.ts`, объект `MATCH`.
- **Ритм ленты:** `lib/feed.ts`, функция `planFeed`.
  - Главный кадр (три колонки из четырёх, вертикальный две): `bigChance`, `bigGap`.
  - Широкий кадр (две колонки): `wideChance`, `wideGap`.
  - Клетка с подписью плёнки: `noteChance`, `noteGap`.
- **Допустимая пустота под крупным кадром:** `lib/masonry.ts` (`tolerance`, `maxGap`).
- **Появление кадров при прокрутке:** компонент `Reveal` в `app/components/Masonry.tsx` (время, сдвиг, задержка).
- **Колонки и отступы:** `app/components/Masonry.tsx` (4 колонки от 768 px, ниже 2).
- **Цвета и рамка кадра:** `app/globals.css`, переменные в `:root`.

## Кадры

Сейчас в прототипе две плёнки (72 кадра): Lucky Color 200 (цветная) и Tasma T-42L (чёрно-белая).
Оригиналы лежат в «Загрузках» и в проект не копируются. Для каждого кадра делаются:

- облегчённая копия для ленты, `public/photos/f` (около 70 КБ);
- крупная копия для просмотра на весь экран, `public/photos/l`;
- цвет и яркость, посчитанные по картинке, `lib/photos/frames.json`.

```bash
npm run import
```

Список папок с кадрами задан в начале `scripts/import-photos.mjs` (`SOURCES`).
Данные плёнки (камера, дата, описание) записаны в `lib/catalog.ts`, массив `ROLLS`.
Номер плёнки в `SOURCES` и `id` в `ROLLS` должны совпадать.
